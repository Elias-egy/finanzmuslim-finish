# finanzmuslim boost

Create a premium, modern landing page for a German brand called “Amanah”.

Amanah is an educational platform for halal investing and Islamic-compliant wealth building. The goal of the page is to generate trust, explain the core promise clearly, and encourage visitors to download a free lead magnet called “Halal Investment Guide”.

Use the attached screenshots as visual inspiration for layout, spacing, typography, section structure, and overall premium feel. Do not copy the reference website directly. Create an original design for Amanah with a similar clean, bold, high-trust business aesthetic.

Important design direction:

- Premium, clean, minimal, trustworthy

- Mostly white background

- Very generous whitespace

- Strong uppercase headlines

- Dark almost-black navigation bar

- Elegant deep green as the primary accent color instead of purple

- Rounded pill-shaped CTA buttons

- High contrast

- No playful illustrations

- No generic stock market graphics

- No crypto-style design

- No overly Islamic ornamental patterns

- The page should feel like a serious premium business education brand

Brand:

- Name: Amanah

- Language: German

- Topic: Halal investing, Islamic-compliant investments, ethical wealth building

- Primary color: elegant deep green

- Secondary colors: white, near-black, light gray

Build the landing page with these sections:

1. Top Announcement Bar

Create a slim announcement bar at the very top in elegant deep green.

Centered text:

“NEU: Halal Investment Guide verfügbar – sichere dir jetzt deinen kostenlosen Einstieg →”

2. Navigation

Below the announcement bar, create a dark almost-black navigation bar.

Left side: text logo “AMANAH”

Right side navigation links:

“Start”, “Guide”, “Über Amanah”, “FAQs”, “Kontakt”

Keep the navigation clean, spacious, and premium.

3. Hero Section

Create a large hero section with a white background and generous vertical spacing.

The layout should be centered and bold.

Main headline:

“MÖCHTEST DU HALAL INVESTIEREN?”

Subheadline:

“Lerne, wie du in renommierte islamkonforme Anlagen investieren kannst – klar, verständlich und ohne Zins, Spekulation oder Unsicherheit.”

Primary CTA button:

“ICH BIN BEREIT ZU INVESTIEREN”

The CTA button should be wide, pill-shaped, deep green, with white uppercase text.

Add large image placeholders on the far left and far right side of the hero section, similar to premium founder/person cutout images. Use neutral placeholders for now because I will add my own images later. The placeholders should not dominate the page but should frame the centered headline.

4. Lead Magnet Section

Directly below the hero section, create a lead magnet section inspired by a premium roadmap/download card.

Use a very light gray background behind the section.

Place a large white rounded card with a subtle shadow.

Inside the card:

- Left side: placeholder mockup for a guide/PDF

- Right side: content

Add a small green badge:

“KOSTENLOS”

Headline:

“HALAL INVESTMENT GUIDE”

Text:

“Erhalte einen klaren Einstieg in halal-konforme Investmentprinzipien, geeignete Anlageklassen und typische Fehler, die du vermeiden solltest.”

CTA button:

“GUIDE KOSTENLOS SICHERN”

5. FAQ Section

Create a clean FAQ section on a white background.

Centered heading:

“FAQs”

Use an accordion layout with large bold questions, dotted or dashed divider lines, and a small chevron icon on the right.

Use these placeholder questions:

- “Was bedeutet halal investieren?”

- “Welche Anlagen sind islamkonform?”

- “Für wen ist Amanah geeignet?”

- “Ist der Guide kostenlos?”

Keep the FAQ minimal and elegant.

6. About Section

Create an “Über Amanah” section.

Use a two-column layout.

Left side: image placeholder with a thick black rectangular frame.

Right side: text content.

Heading:

“ÜBER AMANAH”

Placeholder text:

“Amanah steht für vertrauenswürdige Bildung rund um halal-konformes Investieren. Unser Ziel ist es, Muslimen einen klaren, verständlichen und seriösen Einstieg in islamkonforme Geldanlage zu ermöglichen – ohne Zins, ohne unnötige Komplexität und ohne leere Versprechen.”

The tone should be serious, trustworthy, and educational.

Responsive requirements:

- Fully responsive on desktop, tablet, and mobile

- Mobile-first behavior

- On mobile, stack sections vertically

- Navigation becomes a hamburger menu

- Hero image placeholders should stack or be reduced on mobile

- Buttons should remain large and easy to tap

- Keep spacing premium and uncluttered on all breakpoints

Technical/design requirements:

- Use modern React components

- Use Tailwind CSS styling

- Use clean reusable sections

- Use semantic HTML

- Keep the code organized

- Do not add backend, login, payment, or database features yet

- Focus only on the landing page design and layout
